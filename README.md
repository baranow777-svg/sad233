# Сад семьи Барановых

**Самара, микрорайон Орловский, 233** · интерактивный атлас и дневник растений сада.

Данный сайт — самодостаточная HTML-страница: карточки растений, дневник (дата посадки, возраст, записи, фотографии), архив растений, поиск, общий дневник, импорт/экспорт в Excel. Работает полностью офлайн, без внешних зависимостей и серверов.

## Как разместить на GitHub Pages

Этот репозиторий предназначен для публикации сайта на **GitHub Pages**.

### Вариант 1 — новый репозиторий
1. Создайте репозиторий на GitHub (например `sad-baranovyh`).
2. Зальте в него файлы: `index.html`, `README.md`.
3. Откройте репозиторий → **Settings** → **Pages**.
4. В разделе «Build and deployment»: Source = **Deploy from a branch**, ветка `main` (или `master`), папка `/ (root)`.
5. Сохраните. Готово — сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

### Вариант 2 — профильный сайт
Если репозиторий называется `<ваш-логин>.github.io`, сайт будет на
`https://<ваш-логин>.github.io/`

## Важное примечание о хранении данных

- Страница хранит все внесённые изменения (карточки, дневник, архив, фото) в **localStorage вашего браузера**.
- Это означает: данные сохраняются в каждом браузере/устройстве **отдельно** и НЕ синхронизируются между устройствами автоматически.
- Для переноса данных между устройствами используйте кнопки **«Экспорт (Excel)»** / **«Импорт (Excel)»** на странице.

> Если нужна автоматическая синхронизация между несколькими устройствами — свяжитесь с автором для подключения облачного хранилища.
